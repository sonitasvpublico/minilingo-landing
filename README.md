# MiniLingo Landing

Standalone marketing site for MiniLingo (Web Summit Startup Programme).

**This project does NOT touch the mobile apps** (`mundo-alfabeto` iOS/Android).

## Local

```bash
cd ~/Desktop/minilingo-landing
npm install
npm run dev
```

## Deploy later (only when ready)

Connect this folder to Vercel as a new project. Suggested name: `minilingo` → `minilingo.vercel.app`.
